# Каталог цен AI-моделей

Небольшая программа на Python и SQLite. Она читает сохранённую HTML-страницу каталога, сохраняет модели и цены в локальную базу, показывает таблицу с сортировкой и экспортирует её в CSV. Используются только стандартные модули Python — отдельно устанавливать пакеты не нужно.

В комплекте лежит исходная страница `models.html`. В ней найдено 196 карточек. Цены со страницы указаны за 1 миллион токенов; при импорте цена приводится к этому же основанию. Источник — сохранённый снимок страницы, цены не обновляются из интернета автоматически.

## Импортировать каталог в SQLite

```bash
python3 model_prices.py import models.html
```

По умолчанию база создаётся рядом со скриптом в файле `models.sqlite3`. Повторный импорт обновляет записи моделей по их адресу в каталоге.

## Показать таблицу

```bash
python3 model_prices.py list
```

Сортировка по цене ввода или вывода, названию либо контексту:

```bash
python3 model_prices.py list --sort output
python3 model_prices.py list --sort name --limit 30
```

## Экспортировать CSV для табличного редактора

```bash
python3 model_prices.py export prices.csv
```

## Создать цветную интерактивную таблицу

```bash
python3 model_prices.py html
```

Открой `catalog.html` в браузере. Поиск разбивает запрос на слова, принимает их начала (например, `lun` найдёт `Luna`) и оставляет модели с наибольшим числом совпавших слов. Поэтому запрос `gpt astra lun` найдёт варианты GPT Astra и GPT Luna, не показывая остальные GPT-модели. Рядом с заголовками столбцов есть стрелки: `↑` сортирует по возрастанию, `↓` — по убыванию. Поставщики и цены выделены цветом. Страница автономная и работает офлайн.

Для другой базы добавь `--db путь/к/файлу.sqlite3` перед подкомандой.
