# График процентилей

`percentile_plot.py` строит цветной график для статического массива из 200 случайных значений в диапазоне от 40 до 360.

- По горизонтали: значения, отсортированные по возрастанию.
- По вертикали: процентильный ранг от 0 до 100%.
- Плавная монотонная линия проходит через отсортированные наблюдения.
- Направляющие отмечают медиану на 50% и 90-й перцентиль на 90%.
- Цвет линии меняется вдоль оси значений от светло-зелёного через спектр.

## Запуск

Установи зависимости и выполни скрипт:

```bash
python3 -m pip install -r requirements.txt
python3 percentile_plot.py
```

Скрипт сохранит изображение `random_values_percentiles.png` рядом с собой. Массив задан в начале файла; при запуске он не генерируется заново.
